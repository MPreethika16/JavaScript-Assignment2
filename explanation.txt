task 1:A closure is basically when a function remembers the variables from where it was created even after that outer function is done running.
In the setupCounter example,there is a variable count that is declared inside the function. Then we have two inner functions which are increment and decrement. These two dont forget about count they remembers it.
So every time you call setupCounter(),a new count is created,and the returned object keeps access to it through those inner functions.Even though setupCounter finishes running,the inner functions still keeps track of their own private version of count.
That’s why counterOne and counterTwo don’t interfere with each other they are independent
